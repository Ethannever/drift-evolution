# 漂流进化 - 市场调研报告

## 调研竞品

### 1. diep.io（进化射击 io 游戏）
- **核心玩法**：玩家控制坦克，通过击杀方块和敌人获取经验值升级，每升一级可分配属性点（生命、速度、伤害等），达到一定等级可选择不同职业进化（双管、狙击手、机枪手等 8 种方向）
- **留存机制**：升级进化系统是核心驱动力，每次进化带来全新玩法体验；排行榜激励竞争；局内成长快速（几分钟即可完成一次进化）
- **操作方式**：鼠标瞄准 + WASD/方向键移动，简洁高效
- **视觉风格**：极简几何风格，彩色圆形/方形，无复杂贴图，辨识度极高
- **付费模式**：完全免费，无内购，靠广告维持
- **社交功能**：FFA、2Team、4Team、Domination 等多种模式，实时多人对战
- **关键启示**：
  - 进化树是核心留存点，每次进化让玩家感到"质变"
  - 极简视觉反而降低了门槛
  - 属性分配系统增加策略深度

### 2. surviv.io（2D 俯视 Battle Royale）
- **核心玩法**：2D 俯视角大逃杀，搜刮装备 → 缩圈 → 对抗，每局独立
- **留存机制**：Quest 系统 + Survivr Pass（类似 Battle Pass），通过 XP 升级通行证获取奖励
- **操作方式**：WASD 移动 + 鼠标瞄准射击，移动端触屏操作
- **视觉风格**：简洁的 2D 俯视角，草地/建筑/树木，风格偏写实但简约
- **付费模式**：通行证系统（游戏内赚取），广告
- **社交功能**：Solo、Duo、Squad 模式，组队系统
- **关键启示**：
  - Battle Pass 通行证是成熟的留存机制
  - 局制游戏（每局新开始）降低挫败感
  - 缩圈机制制造紧张感

### 3. raft.io（木筏生存 io 游戏）
- **核心玩法**：在海上木筏上生存，收集漂流物资，建造和扩展木筏，抵御鲨鱼
- **留存机制**：建造系统、生存要素（饥饿/口渴）、进化/升级木筏
- **操作方式**：WASD 移动 + 鼠标交互
- **视觉风格**：卡通风格，明亮配色，海上漂浮物丰富
- **付费模式**：免费 io 游戏模式
- **社交功能**：多人在线，可合作或对抗
- **关键启示**：
  - 海上漂流 + 建造是非常有吸引力的主题
  - 生存要素（饥饿/口渴）增加紧迫感
  - 鲨鱼威胁是经典设计

### 4. narwhale.io（海洋 io 游戏）
- **核心玩法**：控制独角鲸，用角撞击其他玩家，击杀后变大变强
- **留存机制**：简单但令人上瘾的核心循环（击杀 → 变强 → 击杀更强的对手）
- **操作方式**：鼠标控制方向，加速冲刺
- **视觉风格**：极简卡通，蓝色海洋背景
- **付费模式**：免费，广告
- **社交功能**：多人在线 FFA
- **关键启示**：
  - 海洋主题 io 游戏有现成受众
  - "越大越强"的成长感令人满足
  - 操作越简单，受众越广

### 5. 其他相关竞品
- **Agar.io**：分裂/合并机制，最小操作最大乐趣
- **Slither.io**：贪吃蛇 + io，"围杀"机制创造深度
- **Kraken.io**：海洋怪兽 io，进化机制
- **Deep.io**：深海进化 io，从鱼到鲨鱼到鲸鱼的进化链

## 市场分析总结

### 核心发现

1. **进化系统是核心驱动力**：diep.io 和 deep.io 证明，清晰的进化路径（解锁新能力/外观）是 io 游戏最强的留存机制。玩家为了看到下一个形态而持续游玩。

2. **操作必须极简**：成功的 io 游戏都只用 2-3 个输入维度（移动 + 瞄准/冲刺）。复杂操作会流失移动端用户。

3. **每局 5-15 分钟最佳**：io 游戏的精髓是"快速开始、快速获得满足感"。太长的局会让玩家疲劳。

4. **视觉辨识度 > 画面质量**：diep.io 的极简几何风格和 agar.io 的彩色圆形证明，辨识度比精美画面更重要。

5. **"收集-成长-对抗"三角循环**：几乎所有成功 io 游戏都遵循：收集资源/经验 → 角色成长 → 与更强对手对抗。

### 对漂流进化的建议

| 方面 | 建议 |
|------|------|
| 进化系统 | ✅ 已有，保持并强化视觉反馈（进化动画、全屏提示） |
| 操作 | ✅ 已有摇杆，确保移动端体验流畅 |
| 留存 | 添加每日任务、排行榜、进化成就 |
| 平衡 | 前 30 秒必须有正反馈（快速收集第一个资源/第一次进化） |
| 视觉 | 进化后外观必须有明显变化 |
| 社交 | 后期可考虑多人在线（当前单人可接受） |
