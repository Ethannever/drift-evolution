# 漂流进化 (Drift Evolution) — 游戏设计文档 v0.1

> 本文档为《漂流进化》核心设计文档，描述游戏愿景、核心循环、系统架构、数值框架。
> 目标：个人开发者使用 Godot 4 开发，微信小程序 + App 双端发布。

---

## 1. 游戏概述

### 1.1 一句话描述

开局一块木筏，开放式海洋地图，通过漂流收集物资进化载具，从木筏成长为航母或机甲，玩家同屏碰撞/战斗，配件随机掉落。

### 1.2 核心体验关键词

| 关键词 | 含义 |
|--------|------|
| **漂流感** | 玩家不能直接控制方向，靠洋流+帆+推进器被动移动 |
| **进化爽感** | 亲眼见证自己的木筏从小变大，尺度对比强烈 |
| **资源争夺** | PvP碰撞/武器战斗，配件掉落，刺激肾上腺素 |
| **三条进化线** | 海洋线（主）+ 陆地线（分支）+ 天空线（终局） |

### 1.3 参考游戏

- `RAFT`（漂流生存）× `觅长生`（修仙进化）× `Battle Royale`（PvP拾荒）

## 2. 世界观与设定

### 2.1 游戏背景

> 未来，人类文明崩溃。海面上漂浮着无数残骸和物资。幸存者在碎片中求生，从一块木板开始，逐步建造自己的海上帝国——或陆地霸主，或天空传奇。

### 2.2 三条进化线

```
海洋线（主）
═══════════════════════════════════════════════
阶段1 木筏(Raft)       尺寸: 1x1    无武器，只能漂流+收集
阶段2 皮划艇(Canoe)    尺寸: 1x2    简易划桨，被动加速
阶段3 渔船(Fisher)    尺寸: 2x2    货舱+1，撒网功能
阶段4 炮艇(Gunboat)   尺寸: 2x3    1号炮塔，可攻击
阶段5 驱逐舰(Destroyer)尺寸: 3x4    2号炮塔，鱼雷
阶段6 巡洋舰(Cruiser) 尺寸: 4x5    3号炮塔+防空炮
阶段7 航母(Carrier)   尺寸: 5x7    舰载机放飞，区域控制

陆地线（分支，从海洋线触发，需登陆人工岛）
═══════════════════════════════════════════════
触发条件: 海洋线达到炮艇及以上 + 到达人工岛
阶段1 气垫船(Amphib)   由炮艇改装，可上岸
阶段2 两栖突击车       4x4，装甲+机枪
阶段3 主战坦克         4x6，主炮+反应装甲
阶段4 机械兽(Mech)    3x3，双足，装甲+导弹
阶段5 陆地战舰         终极陆地形态，重甲+巨炮

天空线（从航母触发）
═══════════════════════════════════════════════
触发条件: 海洋线达到航母
阶段1 水上飞机         2x2，从航母弹射起飞
阶段2 直升机           2x2，灵活机动
阶段3 喷气机           2x3，高速+空空导弹
阶段4 轰炸机           3x4，对地+炸弹
阶段5 星际战舰         终极天空形态，跨地图，战斗+运输

三条线最终形态都可进化，但中途切换需消耗转换道具。
```

### 2.3 地图设计

| 区域 | 描述 | 物资密度 |
|------|------|----------|
| 核心海域 | 资源中等，PvP频繁 | ★★★ |
| 边缘海域 | 物资稀少但稀有度高 | ★★ |
| 石油泄漏区 | 高风险高回报，有毒但物资爆肥 | ★★★★★ |

| 风暴区 | 全随机事件，大船可硬抗 | ★★★ |

## 3. 核心玩法循环

### 3.1 主循环（玩家视角）

```
[漂流] → [发现物资] → [收集] → [合成进化] → [遭遇其他玩家]
    ↑                                           ↓
    └──────────── [战斗/逃跑/交易] ←────────────┘
```

### 3.2 系统循环

| 循环 | 描述 |
|------|------|
| 漂流循环 | 洋流驱动，玩家微调方向（帆/桨） |
| 收集循环 | 物资生成→玩家收集→存入货舱 |
| 进化循环 | 收集足够材料→选择进化方向→形态升级 |
| 战斗循环 | 碰撞/炮击→伤害计算→配件掉落→拾取/逃跑 |
| 经济循环 | 捡→用/交易→维修/升级→消耗→再捡 |

## 4. 物资与合成系统

### 4.1 物资分类

| 类型 | 示例 | 用途 |
|------|------|------|
| 木材 | 木板、竹子 | 基础建造材料 |
| 金属 | 废铁、铜块、铝片 | 武器/装甲 |
| 布料 | 破帆、绳索 | 帆、防护 |
| 电子 | 电路板、芯片 | 雷达、导航 |
| 燃料 | 汽油、柴油 | 引擎推进 |
| 稀有 | 钛合金、复合材料 | 高级载具 |
| 特殊 | 文物碎片、珊瑚 | 兑换/收藏 |

### 4.2 物资获取方式

1. **海面漂流物资**：随机生成蓝色/绿色/金色物资箱
2. **沉船遗迹**：进入探索，消耗时间，有守卫
3. **击败玩家掉落**：根据伤害值和运气掉落
4. **石油泄漏区**：高风险区，稀有物资为主
5. **人工岛商店**：用游戏币购买基础材料

### 4.3 合成配方（进化材料）

| 进化阶段 | 所需材料 |
|----------|----------|
| 木筏→皮划艇 | 木材x20 + 绳索x5 |
| 皮划艇→渔船 | 木材x50 + 金属x15 + 布料x10 |
| 渔船→炮艇 | 金属x40 + 电子x10 + 布料x15 |
| 炮艇→驱逐舰 | 钛合金x20 + 电子x30 + 燃料x20 |
| 驱逐舰→巡洋舰 | 复合材料x30 + 电子x50 + 燃料x30 |
| 巡洋舰→航母 | 复合材料x60 + 电子x80 + 稀有文物x5 |

## 5. 战斗系统

### 5.1 伤害类型

| 类型 | 说明 |
|------|------|
| 碰撞伤害 | 速度差×质量差，撞落配件 |
| 炮击伤害 | 武器造成，有冷却CD |
| 鱼雷/导弹 | 追踪伤害，高伤害低射速 |
| 防空炮 | 对空专属，陆地线无 |

### 5.2 碰撞系统

```
伤害值 = (攻击方速度 × 攻击方质量 - 防御方速度 × 防御方质量) / 100
最小伤害: 1, 最大伤害: 50（硬上限）
撞击后双方都会减速
```

### 5.3 武器系统

| 武器 | 载具等级 | 射速 | 伤害 | 射程 | 特效 |
|------|----------|------|------|------|------|
| 徒手 | 木筏-皮划艇 | - | 碰撞 | - | 撞落低价值配件 |
| 船桨反击 | 皮划艇 | - | 碰撞+5 | - | - |
| 轻炮 | 炮艇 | 2s/发 | 15 | 300px | - |
| 重炮 | 驱逐舰 | 3s/发 | 30 | 500px | - |
| 鱼雷 | 驱逐舰 | 8s/发 | 50 | 400px | 追踪 |
| 舰炮 | 巡洋舰 | 4s/发 | 45 | 700px | 范围溅射 |
| 防空炮 | 巡洋舰/航母 | 1s/发 | 10 | 400px | 防空 |
| 舰载机 | 航母 | 30s/波次 | 80/波次 | 全图 | 轰炸 |

### 5.4 配件掉落规则

```
掉落判定: 受到伤害时，有 (伤害值 / 100 × 幸运值) % 概率掉落1个配件
         击杀时，100%掉落1-3个配件
         配件品质越高，掉落概率越低

配件价值等级:
  1级(白色): 护甲片、工具箱       → 掉落率50%
  2级(绿色): 发动机、雷达         → 掉落率30%
  3级(蓝色): 重型炮台、弹药库       → 掉落率15%
  4级(紫色): 导弹发射器、装甲板     → 掉落率4%
  5级(金色): 稀有文物、特殊装置     → 掉落率1%
```

## 6. 配件系统

### 6.1 配件类型

| 配件 | 效果 | 安装位置 |
|------|------|----------|
| 护甲片 | +10%减伤（可叠加3层） | 船体四周 |
| 发动机 | +20%移动速度 | 船尾 |
| 雷达 | +30%物资发现范围 | 船顶 |
| 炮台 | +1武器栏位 | 武器位 |
| 货舱 | +50%物资容量 | 船体 |
| 弹药库 | +30%武器射速 | 船体 |
| 医疗箱 | 每分钟恢复1%HP | 船体 |
| 幸运符 | +10%掉落率 | 船体 |

### 6.2 耐久与维修

- 所有配件和船体有耐久度(0-100)
- 战斗消耗耐久，0时配件失效
- 维修需要材料：维修工具 + 金属碎片
- 人工岛可进行完整维修（消耗金币）

## 7. 洋流与漂流系统

### 7.1 洋流机制

```
世界地图被划分为多个洋流区域，每30秒刷新流向
玩家在洋流中被动移动，速度 = 洋流速度 × (1 + 帆效率%)
玩家可以通过:
  - 帆(布料): 利用风向加速
  - 桨(皮划艇+): 短暂逆流加速
  - 引擎(炮艇+): 主动推进，不受洋流限制
```

### 7.2 视野与迷雾

- 每个玩家有固定视野半径（由雷达和载具大小决定）
- 视野外区域为战争迷雾
- 木筏视野: 300px → 航母视野: 800px
- 物资在视野内才会显示

## 8. 社交与经济系统

### 8.1 联盟系统

- 3-5人组队，共享仓库
- 联盟成员可以共享视野（能看到队友看到的物资）
- 联盟领地（人工岛）可建造联盟建筑

### 8.2 交易系统

- 玩家之间可以面对面交易（靠近→弹出交易界面）
- 人工岛有市场：玩家开店，竞价买卖
- 货币：漂流币（游戏币，通过游戏行为产出）

### 8.3 排行榜

| 榜单 | 维度 |
|------|------|
| 总战力榜 | 所有载具+配件的战力之和 |
| 击杀榜 | 累计击败其他玩家数 |
| 漂流时长榜 | 不被击杀存活时间 |
| 收藏榜 | 收集到的文物数量 |

## 9. 成长与数值框架

### 9.1 战力计算

```
载具战力 = Σ(配件战力) + 基础战力
基础战力表:
  木筏: 10 | 皮划艇: 25 | 渔船: 50 | 炮艇: 120 | 驱逐舰: 280
  巡洋舰: 600 | 航母: 1200 | 气垫船: 100 | 坦克: 400 | 机械兽: 800
  水上飞机: 150 | 直升机: 250 | 喷气机: 450 | 轰炸机: 700 | 星际战舰: 2000
```

### 9.2 数值成长曲线

```javascript
// 升级所需物资总量（累计）
const evolutionCost = {
  'raft→canoe':       25,    // 材料点数
  'canoe→fisher':     75,
  'fisher→gunboat':   200,
  'gunboat→destroyer': 500,
  'destroyer→cruiser': 1100,
  'cruiser→carrier':  2500
};

// 战斗伤害成长（载具等级影响）
const damageScale = (attackerLevel) => 10 + attackerLevel * 8;
// 防御成长
const defenseScale = (defenderLevel) => 5 + defenderLevel * 5;
// HP成长
const hpScale = (baseHP, level) => Math.floor(baseHP * Math.pow(1.2, level - 1));
```

### 9.3 物资刷新规则

```
海洋物资刷新:
  每分钟在随机位置生成 3-8 个物资箱
  其中: 60%木材, 20%金属, 10%布料, 5%电子, 3%燃料, 2%稀有

物资箱价值:
  绿色箱子: 价值x1.5, 生成率60%
  蓝色箱子: 价值x3, 生成率30%
  金色箱子: 价值x10, 生成率10%
```

## 11. 开发里程碑

### MVP（目标3-4个月兼职）

| 阶段 | 内容 | 目标 |
|------|------|------|
| M1 | 核心漂流移动 + 物资收集 | 木筏能在海上漂，能捡东西 |

## 12. 质量门禁（开发检查清单）

- [ ] 每阶段必须完成基础功能测试
- [ ] 碰撞系统必须验证：不穿透、不卡位
- [ ] 进化系统必须验证：材料足够则能进化，不足够则提示
- [ ] 网络同步：房间内所有玩家状态一致
- [ ] 性能：60FPS最低，30FPS可接受
- [ ] 所有新增功能必须有对应退出条件（防止无限循环）
