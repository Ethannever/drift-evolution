# 漂流进化 v3.0 迭代规划

> 基于 v2.0.0 市场调研 + 竞品分析 + 当前代码状态的迭代方案
> 创建日期: 2026-05-08

---

## 一、v2.0 现状盘点

### ✅ 已完成
- 核心漂流 + 收集 + 进化循环（7阶段海洋线）
- 战斗系统（碰撞伤害 + 武器射击）
- 16 个任务系统（生存/收集/战斗/进化 4 大类）

| 进化视觉反馈弱 | 进化后外观变化不明显 |
| 背包/技能 UI 未完成 | 按钮存在但功能未接入 |

## 三、迭代内容（按优先级）

### P0 - 必须完成（v3.0 发布门槛）

#### 1. 像素美术升级 🎨
**目标**：每个进化阶段有独特像素船体 sprite

| 阶段 | 外观描述 | 尺寸 |
|------|---------|------|
| 木筏 | 4 块木板拼接，简陋 | 24x24 |
| 皮划艇 | 窄长型，有小帆 | 24x48 |
| 渔船 | 方形船体，有甲板 | 48x48 |
| 炮艇 | 军绿色，甲板有炮台 | 48x72 |
| 驱逐舰 | 灰色，双炮台 + 鱼雷管 | 72x96 |
| 巡洋舰 | 深灰，重型武装 | 96x120 |
| 航母 | 巨大甲板，跑道线 | 120x168 |

- 使用 Aseprite 或在线像素工具生成
- 每个阶段 4 帧动画（idle + 移动）
- 进化时播放 morph 过渡动画（0.5 秒）

#### 2. 海面渲染 🌊
**目标**：让玩家一眼看出"这是海洋"

```
实现方案（纯 Canvas）：
1. 背景层：深蓝→浅蓝渐变（基于深度/区域）
2. 波浪层：正弦波叠加，2-3 层半透明波纹
3. 洋流可视化：半透明箭头/粒子流动方向
4. 泡沫层：船周围白色泡沫效果
5. 光照：水面高光随波浪闪烁
```

- 性能目标：移动端 60fps
- 使用 requestAnimationFrame + 离屏 Canvas 优化

#### 3. 新手引导 🎓
**目标**：前 30 秒零文字教学

```
引导流程（自动触发，无弹窗）：
0-5s:  木筏出现在海面，洋流自动推动，屏幕闪烁"← →"方向提示
5-10s: 第一个物资箱漂过来，高亮闪烁，靠近自动拾取
10-15s: 右上角材料数字跳动，进化按钮闪烁
15-20s: 点击进化，播放进化动画，木筏→皮划艇
20-30s: 皮划艇速度提升，视野扩大，展示"探索更大海域"的成就感
```

- 引导期间暂停敌人生成
- 完成引导后奖励 50 科技点

#### 4. 每日任务系统 📅
**目标**：给玩家"今天还想来"的理由

```
每日任务池（每天随机 3 个）：
- 收集 50 个物资
- 击败 5 个敌人
- 进化到渔船
- 存活 10 分钟不被击败
- 在石油泄漏区收集 10 个物资
- 完成一次进化（任意阶段）

奖励：科技点 / 稀有物资 / 皮肤碎片
```

- 每日 00:00 重置
- 完成全部 3 个额外奖励"黄金宝箱"

#### 5. 成就系统 🏆
**目标**：给长期玩家目标感

```
成就分类：
【收集类】物资大师（收集 1000 个）、稀有猎人（收集 50 个稀有）
【进化类】进化之路（解锁所有阶段）、速通者（5 分钟内到炮艇）
【战斗类】海战英雄（击败 100 个敌人）、以弱胜强（击败高 2 级敌人）
【探索类】探险家（到达所有区域）、幸存者（单局存活 30 分钟）
【特殊类】Bug 猎人（报告 10 个 Bug）、任务达人（完成 100 个任务）
```

- 每个成就解锁对应奖励（科技点/称号/皮肤）
- 成就界面展示进度条

### P1 - 重要增强（v3.0 或 v3.1）

#### 6. 主动技能系统 ⚡
**目标**：增加战斗操作深度

```
技能设计（消耗科技点解锁）：

- 技能栏 UI（2-3 个快捷槽）
- 科技点解锁 + 升级

#### 7. 敌人 AI 增强 🤖
**目标**：让 PvE 有挑战性

```
敌人类型：
- 巡逻者：固定路线巡逻，发现玩家追击
- 伏击者：潜伏在物资密集区，靠近才触发
- 掠夺者：主动追击最近的玩家，速度快但血薄
- 精英：稀有刷新，高血量高伤害，掉落稀有配件
- Boss（人工岛守卫）：超大体型，多阶段战斗
```

- 敌人外观随等级变化（颜色/大小）
- 精英和 Boss 有血条显示

#### 8. 区域系统 🗺️
**目标**：地图不再是"一片海"

```
区域设计（同心圆结构）：
核心海域（中心）：物资中等，PvP 频繁，安全区边界
资源区（中环）：物资密集，敌人多，竞争激烈
石油泄漏区（外环）：高风险高回报，有毒效果（持续掉血）
沉船遗迹（随机）：宝箱 + 守卫 + 文物
风暴区（边缘）：随机事件，视野缩小，洋流紊乱
人工岛（固定点）：安全区 + 商店 + 陆地线入口
```

- 区域切换有过渡动画
- 小地图显示区域边界

#### 9. 小地图增强 🗾
**目标**：提供全局态势感知

```
小地图显示：
- 玩家位置（中心绿点）
- 物资密度（蓝色点云）
- 敌人位置（红色点，视野内可见）
- 区域边界（虚线圆）

## 四、技术方案

### 前端（Canvas 渲染优化）
```javascript
// 分层渲染架构
const layers = {
  background: offscreenCanvas('bg'),     // 海面底色 + 渐变
  water:      offscreenCanvas('water'),  // 波浪 + 洋流
  entities:   offscreenCanvas('entity'), // 船只 + 物资 + 敌人
  effects:    offscreenCanvas('fx'),     // 粒子 + 爆炸
  ui:         offscreenCanvas('ui'),     // HUD + 面板
};

// 只重绘变化的层
function render() {
  layers.background.draw(); // 静态，很少重绘
  layers.water.update();    // 每帧更新波浪
  layers.entities.draw();   // 实体变化时重绘
  layers.effects.update();  // 粒子每帧更新
  layers.ui.draw();         // UI 变化时重绘
}
```
