# 漂流进化 - 多人模式设计

## 架构方案

### 方案A: WebSocket 实时同步（推荐）
- Node.js + ws 库作为游戏服务器
- 每个房间最多 20 人
- 状态同步频率: 20Hz（50ms/次）
- 使用空间分区（Grid）减少同步数据量

### 玩家流程
1. 打开网页 → 自动分配随机昵称 + 随机出生点
2. 选择房间（或自动加入）
3. 进入游戏 → 看到其他玩家实时位置
4. 碰撞/战斗/合作

### 同步数据
- 位置 (x, y)
- 朝向 (rotation)
- 阶段 (stage: raft/canoe/...)
- HP
- 武器状态
- 昵称

### PvP 规则
- 碰撞造成伤害（基于双方阶段差异）
- 击杀掉落物资
- 阶段越高越强，但速度越慢

### 房间系统
- 公开房间: 自动匹配
- 私人房间: 邀请码
- 观战模式

### 防作弊
- 服务端验证关键逻辑（伤害、进化、物资）
- 客户端只负责渲染和输入
- 异常数据包过滤

### 技术栈
- 前端: 现有 HTML5 Canvas
- 后端: Node.js + ws
- 部署: 和现有游戏服务器同进程
- 数据: 内存（无持久化需求）
