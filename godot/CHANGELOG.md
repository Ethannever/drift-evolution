## v1.2.0 (开发中) - 人机协作测试闭环

### 新增系统

#### 🐛 Bug 猎人系统 (BugHunterSystem)
- 玩家报告 Bug 获得科技点奖励
- Bug 追踪流程：报告 → AI 响应 → 修复 → 验证 → 关闭
- 奖励机制：
  - 发现 Bug: +50 科技点
  - 验证修复: +20 科技点
  - 提出建议: +10 科技点
- 排行榜系统

#### 📋 测试任务系统 (TestTaskManager)
- AI 发布测试任务给玩家
- 任务类型：
  - 功能测试：测试新功能
  - 回归测试：验证 Bug 修复
  - 探索性测试：自由探索发现
  - 性能测试：帧率/卡顿
  - 平衡性测试：游戏数值
- 完成奖励 + 完美额外奖励

#### 🔄 闭环流程
```
AI 生成代码
    ↓
发布测试任务
    ↓
玩家测试 → 发现 Bug / 验证功能
    ↓
报告 → AI 修复 → 玩家验证
    ↓
通过 → 合并到正式版
```

#### 新增文件
```
scripts/ai_evolution/
├── bug_hunter_system.gd  # Bug 追踪+奖励
└── test_task_manager.gd   # 测试任务发布

scripts/ui/
└── bug_hunter_ui.gd      # Bug 猎人界面
```

## v1.1.0 (2026-05-03) - 战斗系统

### 新增功能

#### ⚔️ 战斗系统
- **武器组件** (`weapon.gd`)
  - 近战武器（MELEE）- 直接伤害
  - 远程武器（RANGED）- 抛射物
  - 特殊武器（SPECIAL）- 可扩展
  - 冷却时间、弹药系统
  - 击退效果

- **抛射物系统** (`projectile.gd`)
  - 物理移动
  - 碰撞检测
  - 伤害传递
  - 自动销毁

- **敌人AI** (`enemy.gd`)
  - 多种行为模式：追逐、巡逻、伏击、逃跑
  - 自动追踪玩家
  - 掉落物品
  - 死亡处理

- **战斗管理器** (`combat_system.gd`)
  - 敌人生成系统
  - 难度递增
  - 伤害计算
  - 战斗状态管理

#### 🛡️ 载具增强
- 防御属性
- 受伤无敌帧（0.5秒）
- 受伤闪烁效果
- 科技点系统
- 武器装备系统
- 武器切换（Q/Z键）

#### 🎮 控制增强
- **鼠标左键**: 开火
- **Q键**: 切换到下一种武器
- **Z键**: 切换到上一种武器

### 新增文件
```

scripts/ui/

```

### 技术改进
- 碰撞层管理（world/vehicles/items/projectiles）
- 信号驱动的事件系统
- Autoload 架构完善
